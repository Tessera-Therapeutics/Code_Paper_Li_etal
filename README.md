# Code for Li et al., 2026

This repository contains analysis code associated with the manuscript:

**“In vivo Gene Writing with engineered retrotransposons”**
Li et al., 2026
*Link to publication to be added upon release.*

The repository is organized by assay or data modality:

```text
WGS/          Whole-genome sequencing analyses
DISTAL-seq/   DISTAL-seq analyses
Uni-seq/      Uni-seq analyses
scRNA/        Single-cell RNA-seq analyses
```

The code provided here was used to generate, process, or support analyses reported in the manuscript. Each folder contains assay-specific scripts and documentation where applicable.

This repository is intended to support transparency and reproducibility of the computational analyses underlying the paper. Additional details on experimental design, sample processing, and interpretation are provided in the manuscript and associated supplementary materials.
